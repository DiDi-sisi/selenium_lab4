\# Лабораторная работа №4. Параметризованные тесты



\## Описание

В проекте реализован data-driven подход с использованием `@pytest.mark.parametrize`. Входные данные и ожидаемые результаты вынесены из кода в списки кортежей. Тесты покрывают форму логина, страницу с чекбоксами и страницу статус-кодов.



\## Установка и запуск

1\. `python -m venv .venv`

2\. Активация: `.venv\\Scripts\\activate`

3\. `pip install -r requirements.txt`

4\. Запуск: `pytest -v`
